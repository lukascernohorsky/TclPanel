# TclPanel

Standalone modular X11 desktop panel written in Tcl/Tk with a small C/Xlib extension. No XFCE, GTK, Qt, or libwnck dependency.

The initial source release is provided in `dist/tclpanel-0.2-source.tar.gz`. Extract it to obtain the complete source tree, including Tcl modules, the X11 extension, tests, Debian packaging metadata, and a FreeBSD ports template.

See the source archive's README for build requirements, configuration, APIs, and known limitations.
